# WhoLeakMe — XAMPP + VS Code Prototype

## What this project includes
- PHP + MySQL authentication
- User profile management
- Digital footprint scanner: email, username, domain/URL, password indicator
- Local heuristic detection without API keys
- Risk scoring: Low, Medium, High, Critical
- Scan history and detailed findings
- Website threat detection storage
- Notifications
- Report generation and print/save-as-PDF
- Prototype Manifest V3 browser extension
- Database usage matching the supplied ERD tables

## Setup
1. Start **Apache** and **MySQL** in XAMPP.
2. Put this folder inside `xampp/htdocs/wholeakme`.
3. Open `config.php` and set `DB_NAME` to the database name you already created.
4. Ensure your ERD tables exist with the same names/columns shown in the project ERD.
5. Open `http://localhost/wholeakme/`.
6. Register a new account.

## Important: no API key yet
All scan findings are generated by local demonstration heuristics. No Breach Directory, VirusTotal, Google Safe Browsing, Have I Been Pwned, Gmail, or other external service is queried yet.

## Browser extension
Open Chrome/Edge Extensions → Developer mode → Load unpacked → select the `extension` folder.

The extension independently checks simple URL heuristics and shows a warning. The included `api/extension_scan.php` endpoint is prepared for future server integration, but production authentication should be added before sending user data from the extension.

## Database assumptions
The code expects the ERD table names:
`users`, `user_profiles`, `email_addresses`, `breach_results`, `scans`, `scan_results`, `visited_urls`, `threat_detections`, `reports`, `notifications`, `api_logs`.

If your imported SQL uses slightly different column names, update the SQL queries in the PHP files accordingly.
